# Penthouse Print Factory

Tシャツ・プリントサービスサイト。

## ファイル構成

- index.html : トップページ
- legal.html : 特商法ページ
- images : 画像
- bgm : BGMプレイヤー
- block-pop : ブロックポップゲーム
- catch : ぽっちゃんキャッチ
- potato : ポテトゲーム
- road : 道路ゲーム
- sanpo : さんぽゲーム
- shunen : 周年ページ

## 更新ルール

- 特商法ページの修正は legal.html
